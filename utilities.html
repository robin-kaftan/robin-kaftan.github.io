INSTALLATION TUTORIAL: (windows)

  1. Open Windows settings (Win+I) and search VPN Settings.
  2. Click Add VPN, then type any name.
  3. Paste in the IP in the Adress box.
  4. Type "vpn" into the Username and the Password boxes.
  5. Hit connect from that menu or the sound/battery/wifi area.

Results WILL vary from test-to-test. This can be from current network conditions, or because the servers are warming up.
Do not expect these to be fast. They are free for a reason.
